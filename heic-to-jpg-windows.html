HEIC to JPG on Windows

Windows still cannot open HEIC out of the box, so a photo from an iPhone shows a blank thumbnail and refuses to open. Here is how to fix it, with and without installing anything.

Why Windows cannot open HEIC

Windows 10 and 11 ship without the codec needed to decode HEIC. Microsoft licenses HEVC, the compression HEIC relies on, separately and does not bundle it, largely to avoid the per-device licensing cost. The result is that a file your iPhone made perfectly happily shows up on your PC as an icon that opens into nothing.

You have two routes: convert the files so Windows never needs the codec, or install the codec so Windows can read HEIC directly. The first is faster for a one-off. The second makes sense if you deal with HEIC constantly.

The fast way: convert in the browser

You do not need to install anything. Open the HEIC to JPG converter, drag your photos in, and download JPGs. It runs entirely in the browser, so there is nothing to install and, unlike most online converters, the photos are never uploaded to a server. That last part matters here, because HEIC files from a phone carry GPS coordinates showing where each photo was taken.

This works the same on Windows 10 and Windows 11, in Edge, Chrome or Firefox, and it handles a whole folder at once with a zip download at the end.

The permanent way: install Microsoft's codec

If you would rather Windows just opened HEIC like any other image, you need two extensions from the Microsoft Store:

  • HEIF Image Extensions is free, published by Microsoft.
  • HEVC Video Extensions usually costs a small fee, around a dollar, because of the licensing mentioned above. A free OEM version appears for some devices but not all.

Once both are installed, HEIC files open in the Photos app and show thumbnails in File Explorer. The catch is that other programs, such as older Photoshop and many web upload forms, still will not accept HEIC even with the codec installed, because they check the file type themselves. For those, you are back to converting.

Stop the problem at the source

If every photo off your iPhone is going to end up on a PC, change what the phone captures. On the iPhone go to Settings, then Camera, then Formats, then choose Most Compatible. From then on the camera saves JPG and the whole problem disappears. Existing photos are not affected, so you will still need to convert the ones you already have.

Questions

Can I convert HEIC to JPG on Windows without installing anything?

Yes. Use a browser-based converter. Open the HEIC to JPG tool, drag your files in, and download JPGs. Nothing is installed and nothing is uploaded to a server.

Why do my iPhone photos show a blank icon on Windows?

Windows lacks the HEVC codec that HEIC uses, so it cannot render a thumbnail or open the file. Converting to JPG, or installing Microsoft HEIF and HEVC extensions, both fix it.

Does the Microsoft HEVC extension cost money?

Usually around one dollar in the Microsoft Store, because of licensing. A free OEM version exists for some devices. The HEIF Image Extensions package is free.

Will installing the codec let every program open HEIC?

No. It lets the Photos app and File Explorer read HEIC, but many other programs check the file type themselves and still reject it. For those you need to convert to JPG.

How do I stop my iPhone saving HEIC?

On the iPhone go to Settings, Camera, Formats, and choose Most Compatible. The camera then saves JPG. Photos already taken are unaffected.
